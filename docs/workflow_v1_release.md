# 무료 웹 공개 v1.0 구현 워크플로

- 작성: v0.53.1 (2026-11-09)
- 기준 문서: `기획문서.md`의 "[계획] 무료 웹 공개 v1.0" 절, 3.7절(차원석과 상점)
- 이 문서는 계획이다. 각 단계는 `/sc:implement`로 하나씩 진행하고, 단계마다 버전을 올리며 `QA_AND_RULES.md` 인수인계 절을 갱신한다. 커밋은 사용자가 직접 한다.

## 전체 순서와 의존 관계

```
P0 선행 버그 ─▶ P1 측정 시뮬레이터 ─┬─▶ P2 배포·세이브·Firebase ─▶ P3 차원석·상점·미션 ─┐
                                    │                              └─▶ P5-3 시드·순위표 ─┤
                                    ├─▶ P4 지휘관 확장 구조 (P2와 병행 가능) ───────────┤
                                    ├─▶ P5-1·2 변조 단계·3지선다 ───────────────────────┤
                                    └─▶ P7 연구소 확장 (P1 수치 필요) ──────────────────┤
P6 사운드·튜토리얼 (언제든, 독립) ──────────────────────────────────────────────────────┤
                                                                                         ▼
                                                                                  P8 출시 준비
```

- P1이 먼저인 이유: 한 판 30분, 차원석 수급, 변조 보상, 연구소 비용을 모두 실측으로 정해야 하기 때문이다.
- P5-3(순위표)은 P2의 Firebase와 시드 난수가 모두 있어야 한다.

## P1. 밸런스 측정 시뮬레이터 — v0.53.3 완료

> **구현과 결과:** 계획과 달리 고배속(1-2) 대신 가상 시계를 썼다. `tower.js`의 투사체 명중 지연 하한 50ms 때문에 5배속 이상에서는 밸런스가 왜곡되기 때문이다. 미로 봇은 탐욕적 경로 연장 대신 지그재그 가로벽을 쓴다(한 칸 막기로는 같은 길이 우회로가 생겨 이득이 없음). 90판 결과는 `scratch/balance_sim/report.md`와 `기획문서.md` 3.7절.

**방식:** 게임 로직을 따로 재구현하지 않고, 실제 게임을 Edge 헤드리스에 띄워 CDP로 조작한다. 재구현하면 기존 `scratch/sim_harness.js`처럼 현행 코드와 어긋난다.
**위치:** `scratch/balance_sim/` (게임 코드에는 넣지 않음)
