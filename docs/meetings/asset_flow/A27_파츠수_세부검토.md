# A-27 파츠 수 세부 검토

- 작성: Claude, 2026-11-24, v0.55.37
- 배경: R03에서 A-27(파츠 수 v2)이 조건부로 승인되었다. 사용자 의견은 "확정 전에 한번 더 디테일한 검토 후 진행 필요"였다. 이 검토는 리아나 파츠 시트 제작(A-28 5단계) 전에 끝내야 한다.
- 표기: **[측정]** 스크립트로 잰 값. **[확인]** 코드나 사양을 대조한 것. **[의견]** Claude의 판단.

---

## 1. 결론

- **현재 수치는 유지한다.** 전체형은 15-17개에 선택 파츠 최대 2개, 대기형은 10-11개다. 정해진 모션(8절)을 만드는 데 빠진 파츠나 남는 파츠는 없다.
- **빠진 규정이 2개 있다.** 하나는 모자·머리 장식을 어느 파츠에 그릴지이고, 다른 하나는 대기형 캐릭터의 망토다. 리아나에게는 둘 다 없어 리아나 제작은 막히지 않는다. 다만 출시 45명 중에는 해당하는 캐릭터가 있을 것이므로, 아래 3절에서 결정이 필요하다.
- **대기형 파이프라인도 끝까지 동작한다.** 그동안 대기형은 한 번도 돌려 보지 않았는데, 이번에 시험했다(2절).

## 2. 시험 결과

### 2.1 코드와 사양의 파츠 수 일치 [확인]

| 구분 | 사양 5절 | 자리 맞춤 순서 (`fit_core.js` `SHEET_ORDER`) | 검사 (`check_delivery.mjs`) |
|---|---|---|---|
| 전체형 | 머리 6, 몸통 2-3, 팔 4, 다리·무기 3-4 | 같음 | `SHEETS_FULL` 같음 |
| 대기형 | 머리 5, 몸통·팔 4, 무기 1-2 | 같음 | `SHEETS_IDLE` 같음(v0.55.35) |

### 2.2 가짜 납품 시험 [측정]

가짜 납품은 지금 리아나 파츠를 사양 v2 슬롯으로 합쳐, 돌리고 크기를 바꿔 시트에 흩어 놓은 것이다(`make_fake_v2.mjs`, v0.55.37부터 `--type idle` 지원).

| 항목 | 전체형 (17개) | 대기형 (11개) |
|---|---|---|
| 슬롯 이름 | 17/17 | 11/11 |
| 위치 정확(6px·2도·크기 0.03 이내) | 12/17 | 8/11 |
| 정답 배치로 조립한 정지 자세의 c00 정합 (5px 밖) | 0.03% | 0.03% |
| 관절 벌어짐 최대 (대기 / 이동 / 공격 / 피격) | 0.24px 이하 | 0 / 0.05 / 0.02 / 0.04px |

- 대기형의 팔 한 덩어리와 하체 한 덩어리는 런타임에서 문제가 없었다. 아래팔이나 다리를 움직이는 모션이 와도 해당 뼈의 파츠가 없으면 무시된다. 공격 모션까지 재생해 눈으로 확인했다.
- 두 형식 모두 **머리 소체**가 크게 빗나갔다. c00에서 머리카락에 가려져 맞출 그림이 적기 때문이다. v0.55.37에서 시작 위치를 보정해 오차를 줄였지만 여전히 기준 밖이고, "일치 낮음" 경고가 붙는다. 사람 조정(A-31)에서 고친다. 수치는 3.3절에 적었다.
- 대기형에서 빗나간 나머지 두 개는 가까운 팔(33px)과 먼 팔(7.5px)이다. 팔 전체가 한 덩어리라 c00의 팔과 모양이 조금만 달라도 위치가 밀린다.

## 3. 파츠별 검토

### 3.1 유지해도 되는 것 [의견]

| 항목 | 판단 |
|---|---|
| 다리 한 덩어리(무릎 없음) | 2.5등신에 36px 전장이라 다리를 교차하는 걸음으로 충분하다. 큰 보폭, 달리기, 웅크리기는 만들 수 없다. 이런 모션이 필요해지면 그때 무릎을 추가한다 |
| 손을 따로 나누지 않음 | 무기를 쥔 손은 아래팔에 그린다. 손잡이가 손가락 앞을 지나야 하면 선택 파츠 "손가락 덮개"를 쓴다 |
| 상체와 골반 분리(전체형) | 공격할 때 상체를 비트는 데 필요하다. 대기형은 호흡만 하므로 합쳐도 되지만, 이미 상체와 하체로 나뉘어 있어 그대로 둔다 |
| 표정 수 | 전체형 3종(기본, 눈 감음, 공격), 대기형 2종이다. 피격 표정은 따로 만들지 않고 공격 표정과 색 번쩍임으로 대신한다 |
| 선택 파츠 최대 2개(A-04) | 흔들리는 머리 다발 1개와 손가락 덮개 1개 정도가 현실적이다 |

### 3.2 결정이 필요한 것

**G1. 모자, 투구, 왕관, 머리띠를 어느 파츠에 그릴지 (사양에 규정 없음)**
- [확인] 5.1절에는 머리 소체, 앞·옆머리, 뒷머리, 표정만 있다. 머리에 쓰는 물건은 어디에 그릴지 적혀 있지 않다.
- [의견] Claude 제안
  - 머리와 함께 움직이고 흔들리지 않는 장식(모자, 투구, 왕관, 머리띠)은 **앞·옆머리 파츠에 함께 그린다.** 머리 뒤로 넘어가는 부분이 있으면 그 부분은 뒷머리에 그린다.
  - 따로 흔들려야 하는 장식(긴 리본, 깃털)만 선택 파츠로 둔다.
  - 이렇게 하면 파츠 수는 바뀌지 않는다.

**G2. 대기형 캐릭터의 망토, 등 뒤로 늘어지는 천 (사양에 규정 없음)**
- [확인] 겹침 순서상 상체는 하체보다 위에 그려진다(6절). 그래서 몸 뒤로 늘어지는 망토를 상체 파츠에 그리면 다리를 덮어 버린다. 전체형에는 "뒷자락" 슬롯이 있지만 대기형에는 없다. 선택 파츠(A-04)는 UR/U 전용이다.
- [의견] Claude 제안: 대기형에도 **선택 슬롯 "뒷자락" 1개**(몸 뒤로 보이는 망토, 치마 뒷부분)를 둔다.
  - 대기형 파츠 수는 10-11개에서 **10-12개**가 된다.
  - 시트 2(몸통·팔)는 4-5개가 된다. 순서는 상체 → 하체 → 뒷자락 → 가까운 팔 → 먼 팔이다.
  - 사양 5.2절, `SHEET_ORDER.idle`, `SHEETS_IDLE`을 함께 고친다.

**G3. 날개, 꼬리 (다른 종족)**
- 사양 10절대로 해당 종족을 만들 때 추가 파츠로 정한다. 이번에는 결정하지 않는다.

### 3.3 머리 소체 자동 맞춤 (R03 4.3 정리안 3) [측정]

| 방법 | 전체형 위치 / 회전 / 크기 오차 |
|---|---|
| 이전: 기본 표정 위치에서 40px 안 | 115px / 18.6도 / 0.09 |
| **v0.55.37: 뼈대상 머리-얼굴 거리만큼 위로 옮긴 곳에서 60px 안** | **55px / 12.6도 / 0.09** |
| 회전 범위를 넓힌 경우(채택 안 함) | 64px / 3.1도 / 0.25 |

- 줄어들긴 했지만 머리 소체는 여전히 사람이 맞춰야 한다. 가짜 시트는 파츠를 ±12도 돌려 놓았는데, 실제 납품이 바로 세운 그림이면 결과가 더 나을 수 있다(예상). 실제 b00과 리아나 납품에서 다시 잰다.
