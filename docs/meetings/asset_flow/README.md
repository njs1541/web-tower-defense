# 캐릭터 에셋 플로우 3인 회의 운영 방법

사용자, Claude, Gemini가 캐릭터 에셋 제작 흐름을 회차별로 다듬기 위한 폴더다.

## 역할

| 참석 | 맡는 일 |
|---|---|
| 사용자 | 안건 승인/보류/반려, 최종 결정, Gemini에 지시문 전달 |
| Claude | 웹 조사, 조사 보고서와 회의록 작성, 에셋 요구 사양, 조립·모션·게임 연동, 시제품 |
| Gemini | 같은 주제 독립 조사, 회의록 검토와 추가 의견, 이미지 프롬프트와 제작(전담) |

## 한 회차의 순서

1. **① 조사 (Claude):** `Rnn_조사보고서.md` 작성. 출처 URL과 조사일, 사실/의견 구분, 신뢰도.
2. **② 회의록 (Claude):** `Rnn_회의록.md` 작성. 안건 ID(A-01...), Claude 제안, 결정 필요 사항, 검토 요청 지시문.
3. **③ 검토 (Gemini):** 사용자가 회의록 4.1절 지시문과 회의록 전체를 Gemini에 붙여 넣는다. 답은 4.2절에 그대로 옮긴다.
4. **④ 승인 (사용자):** 5절 표에 안건별 결정과 의견을 적는다.
5. **정리 (Claude):** 승인 안건을 `DECISIONS.md`로 옮기고, 승인된 기술안의 시제품을 `test/`에 만든 뒤, 다음 회차 ①에 결과를 싣는다.

## 규칙

- 안건 ID는 회차가 바뀌어도 유지한다. 새 안건은 다음 번호를 쓴다.
- 종료: 모든 안건 승인 또는 R03 도달. R03에서도 남은 안건은 사용자가 따로 정한다.
- 기술안은 시제품 확인 전에는 "승인(시제품 대기)"으로 두고, 확인 후 확정한다.
- Claude는 이미지 프롬프트를 쓰지 않는다. 이미지 제작에 영향을 주는 안건은 Gemini 의견을 받아야 결정할 수 있다.
- 회의 문서를 고칠 때도 프로젝트 규칙대로 게임 버전을 올린다.
