# SD 캐릭터 파츠 제작 사양 v2 (따로 그리기 방식)

이 문서는 이미지 제작에 필요한 조건을 정리한 사양서다. 프롬프트는 포함하지 않는다.

- **v2 (2026-11-24, v0.55.29):** 3인 회의 R02 결정(A-12, A-13, A-19, A-20, A-21, A-23, A-25)을 반영했다. 근거는 [DECISIONS.md](../docs/meetings/asset_flow/DECISIONS.md).
- **v2.1 (2026-11-24, v0.55.35):** R03 결정을 반영했다. 2.2절 배치 순서 확정(A-26), 한 장 파츠 수 3-6개, 떨어진 조각 판정, 4절 턱 검사 방법, 5.1절 표정 범위, 5.2절 대기형 시트 3장 고정(A-32). 파츠 수(A-27)는 승인되었지만 확정 전에 세부 검토를 한 번 더 한다.
- **v1 (잘라내기 방식):** [ASSET_SPEC_v1.md](ASSET_SPEC_v1.md). 지금 `test/incoming/`에 있는 바디 b01-b09와 리아나 파츠는 v1으로 만든 시험본이다.

**v1에서 바뀐 점**
1. 파츠를 완성본에서 잘라내지 않고, 완성본을 참고해 **따로 그린다.**
2. 파츠는 **제자리에 그리지 않아도 된다.** 한 장에 몇 개씩 흩어 그리고, 자리는 Claude의 맞춤 도구가 맞춘다.
3. 종족 공통 바디 그림이 없어졌다. 공통인 것은 **뼈대(관절 위치)와 모션**뿐이고, 파츠는 캐릭터마다 **몸과 옷을 함께** 그린다.
4. 기준 바디 b00은 게임에 쓰지 않는 **회색 마네킹**이다. b01-b09는 만들지 않는다.
5. 표정은 눈·입만 따로 그리지 않고 **이목구비가 그려진 얼굴 한 덩어리**로 그린다.

## 1. 구조

게임 안에서 캐릭터는 투명 파츠를 겹쳐 그리고, 관절마다 코드로 회전시켜 움직인다.

| 이미지 | 장수 | 용도 |
|---|---|---|
| b00 기준 마네킹 | 종족마다 1장 | 비율, 자세, 관절 위치의 기준. 게임에 쓰지 않는다 |
| c00 완성본 | 캐릭터마다 1장 | 위치와 모습의 정답 그림. 파츠 자리 맞춤의 기준. 게임에 쓰지 않는다 |
| 파츠 시트 | 캐릭터마다 3-4장 | 움직일 파츠를 몇 개씩 따로 그린 그림. Claude가 떼어 내고 자리를 맞춘다 |

**모션용 그림은 필요 없다.** 공격, 피격 같은 동작은 파츠 회전으로 만든다. 예외는 표정 갈아 끼우기다.

## 2. 공통 규격

### 2.1 b00, c00 (기준 그림)

| 항목 | 규격 |
|---|---|
| 캔버스 | 1024×1024px |
| 형식 | PNG (JPG 금지) |
| 배경 | 단색 `#00FF00`. 그림에 녹색이 있으면 `#FF00FF`를 쓰고 납품 시 알린다 |
| 배경 판정 | 녹색: G > 150, R < 120, B < 120. 마젠타: R > 200, B > 200, G < 80 |
| 머리 꼭대기 | y = 180 (합격 170-190) |
| 턱(머리 아래 끝) | y = 약 460 (머리 높이 약 280px, 합격 260-300). 목은 턱 아래에 따로 그린다 |
| 발바닥 선 | y = 880 (합격 870-890) |
| 몸 중심선 | x = 약 512 |
| 비율 | 2.5등신 (전체 키 약 700px, 합격 680-720) |
| 방향 | 화면 오른쪽을 향한 3/4 측면 |
| 그림체 | 굵고 선명한 외곽선, 셀 셰이딩 |

**포즈:** 똑바로 선 자세. 양팔은 몸통에서 떨어뜨려 살짝 벌리고, 팔꿈치는 조금 굽힌다. 다리도 어깨너비로 벌려 서로 겹치지 않게 한다. 무기와 날개가 들어갈 여백이 있어야 한다.

**기준선 가이드:** [guide/guide_template.png](guide/guide_template.png)(1024×1024, 투명 배경)를 생성 결과 위에 겹쳐 비율과 관절 위치를 확인한다. 표시 내용은 7절.

| 항목 | 규격 |

| 납품 전 재배치 | 생성 결과의 순서나 간격이 어긋났으면 파츠를 잘라 다시 놓아도 된다. **위치만 옮기고 크기를 바꾸거나 가장자리를 다시 다듬지 않는다**(반투명 경계가 깨진다) |

### 2.3 넣으면 안 되는 것 (b00, c00, 파츠 시트 공통)

글자, 숫자, 라벨, 칸 테두리, 바닥 그림자, 후광, 배경 효과, 빛 번짐, 잔상, 배경 그라데이션. 빛 번짐과 그라데이션은 배경 제거 때 가장자리를 망가뜨린다.

외곽선과 배경 사이의 1-2px 녹색 번짐은 피하기 어렵다. 이 정도는 빌드 도구(`test/tools/export_rig.mjs`)가 지운다.

## 3. 파츠를 그리는 규칙

1. **원화에서 잘라내지 않고 따로 그린다.** c00을 참고 이미지로 붙여 같은 그림체, 색, 선 굵기로 그린다.
2. **파츠 하나는 닫힌 완전한 형태로 그린다.** 다른 파츠에 가려지는 부분(몸통 뒤 어깨, 앞머리 뒤 이마, 칼자루 전체)도 끝까지 완성한다.
3. **관절 끝은 반원(돔) 모양으로 둥글게 마감하고, 관절 너머로 30-40px 더 그린다.** 다른 파츠 안으로 들어가는 이 겹침 부분은 단면에 어두운 외곽선을 긋지 않고 안쪽 채움색으로 마감한다.
4. **몸과 옷을 한 파츠로 그린다.** 예: 소매 입은 위팔, 바지와 신발을 신은 다리, 흉갑을 입은 상체. 옷만 따로 그리거나 맨몸만 따로 그리지 않는다.
5. **다른 부위를 섞어 그리지 않는다.** 다리 파츠에 손이나 칼자루, 상체 파츠에 방패 테두리가 남으면, 움직일 때 그 조각이 원래 자리에 남는다.
6. **한 파츠는 한 덩어리로 그린다.** 떨어진 장식(귀걸이, 머리핀)은 몸에 붙여 그린다. 떨어진 조각은 다른 파츠로 잘못 분리된다.
7. **앞뒤에 모두 걸치는 것은 나눈다.** 예: 몸 앞과 뒤를 모두 지나는 망토, 치마의 앞자락과 뒷자락.
8. **원화가 왼쪽을 향하면** 좌우를 뒤집어 오른쪽 3/4 시선으로 맞춘 뒤 참고 이미지로 쓴다. 뒤집으면 글자나 비대칭 장식(가르마, 문장 방향)이 바뀌므로 c00에서 원래 디자인대로 고친다.

## 4. 기준 마네킹 b00 (`test/incoming/body_human/b00_master.png`)

성인 여성 체형을 2.5등신으로 줄인 중립적인 몸에 **회색 바디슈트와 회색 단순 신발을 입힌다.** 머리카락과 이목구비가 없는 민머리로 그린다.

- **옷을 입은 것이 한눈에 보여야 한다.** 바디슈트 색은 `#8A8F98` 정도의 중간 회색으로 하고, 피부색이나 살구색은 쓰지 않는다. 피부와 옷의 경계선(목, 손목, 발목)이 선명해야 한다.
- 바디슈트는 목 아래부터 손목, 발목까지 덮는다. 맨살은 머리, 목 윗부분, 손만 둔다. 발가락은 그리지 않는다.
- 가슴과 골반의 윤곽을 그리지 않는다. 상체는 단순한 원통형에 가깝게 그려 체형을 강조하지 않는다.
- 다리 사이에 틈을 두어 허벅지가 서로 닿지 않게 한다.
- 수치는 2.1의 기준선을 따른다. 자동 검사는 목의 가장 좁은 곳을 찾은 뒤, 그 위에서 폭이 다시 넓어지기 시작하는 줄을 턱으로 잡아 머리 높이(머리 꼭대기-턱)를 잰다. 목을 지나치게 짧게 그릴 필요는 없다.
- 관절 위치(어깨, 팔꿈치, 고관절 등)가 눈으로 구분되게 그린다. Claude가 b00에서 관절 위치를 실측해 종족 표준 관절 좌표로 쓴다.

b00은 종족마다 1장이다. 같은 종족의 모든 캐릭터 c00은 b00과 같은 비율, 같은 자세로 그린다.

## 5. 캐릭터 파츠 (몸·옷 일체형)

### 5.1 전체형 (UR, U: 전장 + 도감·지휘관 선택, 전체 모션)

| 시트 | 파일 이름 | 파츠 | 범위 |
|---|---|---|---|
| - | `c00_complete.png` | 완성본 | b00 + 원화를 참고한 전신. 1024 규격(2.1) |
| 1 머리 | `sheet1_head.png` | 머리 소체 | 얼굴 피부, 귀, 목 윗부분. 이목구비 없음 |
| | | 앞·옆머리 | 앞머리와 옆머리. 얼굴은 비움 |
| | | 뒷머리 | 얼굴 뒤로 넘어가는 머리 전체 |
| | | 표정 3종 | 기본, 눈 감음, 공격. **각각 머리 소체에서 귀와 목만 빼고 얼굴 피부면 전체(턱선-이마)를 같은 윤곽·같은 크기로 그린 뒤, 그 안에 이목구비를 그린 한 덩어리**다. 세 장의 얼굴 윤곽과 크기가 같아야 한다. 기본 표정을 먼저 확정하고 나머지 둘은 그 윤곽을 그대로 두고 눈·입만 바꾸는 방식을 권장한다 |
| 2 몸통 | `sheet2_body.png` | 상체 | 옷 입은 목-허리. 어깨 관절 돔 포함 |
| | | 골반 | 옷 입은 허리-고관절. 벨트, 치마 앞자락 포함 |
| | | 뒷자락 | 다리 뒤로 보이는 치마·튜닉·망토 뒷부분 (있는 캐릭터만) |
| 3 팔 | `sheet3_arms.png` | 가까운 위팔 | 소매 입은 어깨-팔꿈치 |
| | | 가까운 아래팔 | 팔꿈치-손끝. 무기를 쥔 손 모양 |
| | | 먼 위팔 | 소매 입은 어깨-팔꿈치 |
| | | 먼 아래팔 | 팔꿈치-손끝. 보조무기·방패를 든 손 모양 |
| 4 다리·무기 | `sheet4_legs_weapons.png` | 가까운 다리 | 바지·신발 포함 고관절-발끝 한 덩어리 |
| | | 먼 다리 | 같은 범위 |
| | | 주무기 | 무기 전체. 손에 가려지는 손잡이까지 완성, 손은 그리지 않음 |
| | | 보조무기 | 방패 등 (있는 캐릭터만) |

- **가까운 쪽(near)** 은 보는 사람에게 가까운 쪽이다. 오른쪽을 향한 캐릭터의 오른팔, 오른다리다. **먼 쪽(far)** 은 그 반대다.
- 파츠 수: 머리 6, 몸통 2-3, 팔 4, 다리·무기 3-4. 캐릭터에 따라 15-17개.
- **추가 파츠(선택, 캐릭터당 최대 2개, A-04):** 흔들림용(양갈래, 긴 옆머리 다발, 망토, 리본처럼 자연 경계가 있는 부위)과 손가락 덮개(무기 손잡이를 감싸는 손가락만 그린 작은 조각. 무기가 팔 앞을 지나가게 할 때)를 합쳐 2개까지. 앞머리와 치마 앞자락은 나누지 않는다.

### 5.2 대기형 (C, UC, R, SR: 도감·지휘관 선택만, 대기 모션)

대기 모션은 다리를 움직이지 않고 팔은 조금만 흔든다. 그래서 하체와 팔을 합친다.

| 전체형에서 | 대기형에서 |
|---|---|
| 표정 3종 | 표정 **2종**: 기본, 눈 감음 (공격 표정 없음) |
| 골반, 뒷자락, 가까운 다리, 먼 다리 | **하체** 1개 (허리-발끝 전체, 치마·바지·신발 포함) |
| 위팔 + 아래팔 (가까운 쪽, 먼 쪽) | **팔** 2개 (어깨-손끝 한 덩어리) |
| 그 외 | 전체형과 같다 |

파츠 수: 머리 5, 상체 1, 하체 1, 팔 2, 무기 1-2. 10-11개. **시트는 다음 3장으로 고정한다**(파일 이름과 배치 순서를 도구가 그대로 읽는다).

| 시트 | 파일 이름 | 배치 순서 (2.2절) | 개수 |
|---|---|---|---|
| 1 머리 | `sheet1_head.png` | 머리 소체 → 앞·옆머리 → 뒷머리 → 기본 표정 → 눈 감음 | 5 |
| 2 몸통·팔 | `sheet2_body_arms.png` | 상체 → 하체 → 가까운 팔 → 먼 팔 | 4 |
| 3 무기 | `sheet3_weapons.png` | 주무기 → 보조무기(있는 캐릭터만) | 1-2 |

검사와 자리 맞춤은 대기형임을 지정해 돌린다: `check_delivery.mjs char <폴더> idle`, `prepare_fit.mjs <폴더> --type idle`.

대기형을 나중에 전장에 내보내려면 빠진 파츠만 추가로 그린다.

**리아나는 C등급이지만 전체형으로 만든다.** 전체 모션을 시험하기 위한 첫 캐릭터이기 때문이다.

### 5.3 리아나 참고 사항

갈색 단발, 갈색 눈. 은색 흉갑과 갈색 어깨끈, 흰 튜닉(소매를 걷어 아래팔은 맨살), 갈색 벨트, 남색 바지, 갈색 부츠, 강철 장검, 날개 달린 투구 문양의 나무 방패. **원화의 배경과 등급 배지는 무시하고, 잘린 부츠는 이어서 완성한다. 칼집은 그리지 않는다**(파츠가 없으므로 c00에도 넣지 않는다). 칼은 가까운 손에 쥐고 방패는 먼 팔에 든다.

## 9. 납품 전 확인

- [ ] 파일 이름이 5절 표와 같다.
- [ ] 모두 PNG다. b00, c00은 1024×1024다.
- [ ] 배경이 완전한 단색이고 그라데이션이나 그림자가 없다.
- [ ] 글자, 숫자, 칸 테두리가 없다.
- [ ] b00, c00을 가이드(7절)와 겹쳤을 때 기준선 합격 범위 안에 있다.
- [ ] 파츠 시트에서 파츠끼리 닿지 않는다.
- [ ] 각 파츠에 다른 부위가 섞여 있지 않다.
- [ ] 관절 끝이 둥글고 겹침 여백이 있다.
- [ ] 표정 패치(전체형 3종, 대기형 2종)의 얼굴 윤곽과 크기가 같다.
- [ ] b00에 회색 바디슈트와 신발이 분명히 보이고, 벗은 몸처럼 보이지 않는다.
- [ ] `node test/tools/check_delivery.mjs`가 실패 0건이다.

**품질 기준:** 지휘관은 모두 성인 여성이다. 2.5등신이어도 아동처럼 그리지 않으며, 바디와 의상 모두 노출과 체형 강조 없이 제작한다.
