# SD 캐릭터 파츠 제작 사양 (리아나 1차 테스트)

이 문서는 이미지 제작에 필요한 조건을 정리한 사양서다. 프롬프트는 포함하지 않는다.

## 1. 구조

게임 안에서 캐릭터는 투명 파츠를 겹쳐 그리고, 관절마다 코드로 회전시켜 움직인다.

- **종족 공통 바디:** 종족마다 1벌만 만들고 같은 종족 캐릭터가 함께 쓴다.
- **캐릭터 파츠:** 얼굴, 머리카락, 의상, 무기만 캐릭터별로 만들어 바디 위에 올린다.
- **모션용 이미지는 필요 없다.** 공격, 피격 같은 동작은 파츠 회전으로 만든다. 예외는 표정 3종뿐이다.

이번 테스트에서 만들 이미지는 **인간족 바디 10장, 리아나 15장, 총 25장**이다. 이후 캐릭터는 등급에 따라 11장 또는 15장을 만든다(5.1절).

## 2. 모든 이미지의 공통 규격

**가장 중요한 규칙은 파츠를 칸에 모아 그리지 않는 것이다.** 파츠 1개당 이미지 1장으로, 캔버스 안의 위치를 옮기지 않고 기준 이미지와 같은 자리에 둔다. 저장한 파일을 그대로 겹쳤을 때 캐릭터가 완성되어야 한다.

| 항목 | 규격 |
|---|---|
| 캔버스 | 1024×1024px, 파일마다 동일 |
| 형식 | PNG (JPG 금지) |
| 배경 | 단색 `#00FF00`. 파츠에 녹색이 있으면 `#FF00FF`를 쓰고 납품 시 알림 |
| 머리 꼭대기 | y = 약 180 |
| 발바닥 선 | y = 약 880 |
| 몸 중심선 | x = 약 512 |
| 비율 | 2.5등신 (전체 키 약 700px, 머리 높이 약 280px) |
| 방향 | 화면 오른쪽을 향한 3/4 측면 |
| 그림체 | 굵고 선명한 외곽선, 셀 셰이딩 |

**포즈:** 똑바로 선 자세. 양팔은 몸통에서 떨어뜨려 살짝 벌리고, 팔꿈치는 조금 굽힌다. 다리도 어깨너비로 벌려 서로 겹치지 않게 한다. 무기와 날개가 들어갈 여백이 있어야 한다.

**넣으면 안 되는 것:** 글자, 숫자, 라벨, 칸 테두리, 바닥 그림자, 후광, 배경 효과, 빛 번짐, 잔상. 빛 번짐은 배경 제거 때 가장자리를 망가뜨린다.

### 파츠 공통 규칙

1. **가려진 부분까지 완성해서 그린다.** 몸통에 가려진 어깨, 앞머리에 가려진 이마처럼 원래 안 보이던 부분도 끊기지 않게 채운다. 관절이 회전하면 그 부분이 드러난다.
2. **관절은 겹치게 자른다.** 위팔의 아래쪽 끝과 아래팔의 위쪽 끝은 둥글게 처리하고, 관절 너머로 이미지 기준 **30~40px씩** 더 그린다.
3. **파츠에는 해당 부위만 그린다.** 다른 부위가 조금이라도 남으면 움직일 때 함께 떠다닌다.
4. **파츠 안쪽은 비어 있어도 된다.** 의상 파츠에는 몸을 그리지 않는다.

### 관절 위치

관절 좌표는 받은 뒤 도구에서 지정하므로 이미지에 표시하지 않는다.

## 4. 인간족 공통 바디 (`test/incoming/body_human/`)

**b00 기준 바디:** 성인 여성 체형을 2.5등신으로 줄인 중립적인 몸에 **회색 바디슈트와 회색 단순 신발을 입힌다.** 머리카락과 이목구비가 없는 민머리로 그린다.

- **옷을 입은 것이 한눈에 보여야 한다.** 바디슈트 색은 `#8A8F98` 정도의 중간 회색으로 하고, 피부색이나 살구색은 쓰지 않는다. 피부와 옷의 경계선(목, 손목, 발목)이 선명해야 한다.
- 바디슈트는 목 아래부터 손목, 발목까지 덮는다. 맨살은 머리, 목 윗부분, 손만 둔다. 발가락은 그리지 않는다.
- 가슴과 골반의 윤곽을 그리지 않는다. 상체는 단순한 원통형에 가깝게 그려 체형을 강조하지 않는다.
- 다리 사이에 틈을 두어 허벅지가 서로 닿지 않게 한다. 다리를 따로 분리하기 위해 필요하다.

**납품 전 수치 확인(b00 전용):** 머리 꼭대기 y = 170~190, 발바닥 y = 870~890, 머리 높이 260~300px, 전체 키 680~720px.

### 5.1 등급별 제작 범위

| 등급 | 사용처 | 모션 | 파츠 |
|---|---|---|---|
| **UR, U** | 전장 + 도감·지휘관 선택 | 전체 | **전체형 15장** (위 표 전체) |
| **C, UC, R, SR** | 도감·지휘관 선택만 | 대기만 | **대기형 11장** (아래) |

**대기형은 다리를 움직이지 않으므로 하의를 1장으로 합치고, 공격 표정을 뺀다.**

| 전체형에서 | 대기형에서 |
|---|---|
| `c05_face_attack` | 만들지 않음 |
| `c07`, `c08`, `c11`, `c12` (튜닉 앞뒷자락, 다리 의상 2장) | `c15_lower.png` 1장으로 통합 |
| 그 외 `c00`~`c04`, `c06`, `c09`, `c10`, `c13`, `c14` | 전체형과 동일 |

`c15_lower.png`는 허리 아래 의상 전체를 몸 없이 그린 파츠로, 치마, 바지, 신발을 모두 포함한다. 겹침 순서는 6절의 8번 `b03` 골반 바로 위다.

대기형을 나중에 전장에 내보내려면 빠진 파츠(`c05`, `c07`, `c08`, `c11`, `c12`)만 추가하면 된다.

**리아나는 C등급이지만 전체형으로 만든다.** 전체 모션을 시험하기 위한 첫 테스트이기 때문이다.

## 8. 납품 전 확인

- [ ] 25장이 모두 있고 파일명이 표와 같다.
- [ ] 모두 1024×1024 PNG다.
- [ ] 파일을 순서대로 겹치면 c00과 위치가 맞는다. 어긋남은 약 5px 이내다.
- [ ] 배경이 완전한 단색이고 그라데이션이나 그림자가 없다.
- [ ] 글자, 칸 테두리가 없다.
- [ ] 의상 파츠에 살이나 몸이 남아 있지 않다.
- [ ] 바디에 회색 바디슈트와 신발이 분명히 보이고, 벗은 몸처럼 보이지 않는다.
- [ ] 소매, 다리 등 관절 부분에 겹침 여백이 있다.

**품질 기준:** 지휘관은 모두 성인 여성이다. 2.5등신이어도 아동처럼 그리지 않으며, 바디와 의상 모두 노출과 체형 강조 없이 제작한다.
